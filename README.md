# Microwave · The Alliance 聯盟

An interactive bilingual exhibition invitation. 四頁文字、光口過場與中英雙語邀請函。

## Website

Publish with GitHub Pages from the `main` branch, `/ (root)`. The entry point is `index.html`.

All styles, animation scripts and the subset font are embedded in the HTML. Visitors do not need an account. No build step or external asset service is required.

## Font

The embedded Noto Sans TC subset is distributed under the SIL Open Font License 1.1. See `OFL.txt`.

## Updates

Replace `index.html` to update the invitation while keeping its public URL and QR code unchanged.
